Arc → Chrome

Star on GitHub

Move your Arc spaces, pinned tabs, folders and favorites into Chrome, and send each space to the right Chrome profile. Everything runs in this page; your data is never uploaded.

  1. In Arc, open Settings → Advanced → Export data. Arc saves Arc Data Export.md.
  2. Drop that file below.
  3. Pick which Chrome profile each space goes to, then download and import.

No Arc export handy?

Optional: keep your custom tab names

Arc's export only contains URLs, so bookmarks get tidy names made from each link. To keep the exact names you gave tabs in Arc, also drop StorableSidebar.json: in Finder press ⌘ ⇧ G, paste ~/Library/Application Support/Arc/, and drag that one file (not the dated backups) onto the box.

Good to know

Each Arc space becomes a bookmark folder holding its Favorites, pinned tabs and nested folders. Chrome places imported bookmarks in an “Imported” folder on the bookmarks bar.

Passwords: in Arc open arc://settings/passwords and export them as CSV, then import that file at chrome://password-manager/settings. Delete the CSV afterwards.
